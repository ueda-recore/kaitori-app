# 外部買取アプリ 試作

## 起動（あなたのPCで）
Node.js 18以上が必要です。

    cd kaitori-proto
    RECORE_API_KEY="（テスト店舗のAPIキー）" RECORE_STORE_ID="（任意:店舗固定）" node server.js
    # → http://localhost:3000 をスマホ/タブレットで開く（同一Wi-Fiなら http://PCのIP:3000）

- キー未設定だとMOCKモード（ダミー応答）で画面だけ試せます。
- APIキーはサーバーの環境変数にだけ置きます。ブラウザには渡りません。
- Authorizationに接頭辞（例 `Bearer `）が必要な場合: `RECORE_AUTH_PREFIX="Bearer "`
- 画面下の「API通信ログ」に全リクエスト/レスポンスが残ります。「ログをコピー」で共有できます（個人情報を含むので注意）。

## 試す順番
1顧客 → 2商品 → 3ケース作成 → 4本人確認 → 5サイン → 6査定承認・支払い → 7完了・検証

## 注意（必ずテスト店舗で）
本番店舗のキーで実行すると、実際の会員・買取ケース・本人確認が作られます。

## 仕様から推測して組んでいる箇所（失敗したらログで確認して直す）
- 買取ケース作成のbody（顧客項目をトップレベルに置く形）
- 添付ファイル登録のbody（file_key / tag / file_name。本人確認の仕様に倣った）
- 精算の `tenders[].payment` の値（CASH と仮置き）
- 会員作成の `status: ACTIVE`
- 一覧レスポンスが配列か `{data:[...]}` か（配列前提。違えば要修正）
